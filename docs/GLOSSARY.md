# Terms

| Term | Meaning |
| --- | --- |
| Activity | Focus, Short Break, or Long Break |
| Period | One timed activity |
| Cycle | The configured number of completed focus periods and their breaks |
| Start | Begin a ready period; plays its start cue |
| Pause / Resume | Suspend / continue a period without another start cue |
| Reset Period | Stop and return the current activity to its full duration |
| Skip Period | Move to the next activity without focus credit |
| Reset Cycle | Return to the first ready focus period |
| Sound cue | Audio played once at an activity start or completion |

| Statistics | Period summaries, focus-time chart and activity log |
| Focus time | Recorded running focus time, including partial activities, excluding pauses |
| Completed focuses | Focus periods that reached their deadline |
| Activity log | Dated history of ended focus and break periods |

| Import Flow CSV | Preview and merge a local exported timesheet into activity history |
| Duplicate | A previously recorded source ID or matching activity/start/end/duration/outcome |
| Estimated timing | Preserved active duration distributed across an interval without known pause positions |
