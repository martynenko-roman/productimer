# Flow reference measurements and adaptation

Source: `docs/screens/03-long-break.png`. `measure.swift info` reports 776 × 584 pixels, 388 × 292 points at scale 2. No full desktop capture was used.

Reference parts: centered activity heading, very large thin system countdown, four cycle dots, one primary pause action, and grouped top-right utility controls. Settings and notification groups are recorded in the screen index.

Productimer retains that hierarchy and cycle behavior, with native Mac toolbar/buttons and Settings tabs. Its default window is 560 × 480 points, with minimum 480 × 420; a 104-point rounded system font and 12-point cycle dots. Native Settings are 600 points wide. Spacing uses `Space`.

This is a scoped structural adaptation, not a measured pixel replica. Flow's saturated background, proprietary glyphs, tag/statistics controls and brand are replaced with an adaptive accent wash, SF Symbols in controls, and an original hourglass app icon. Dark reference screenshots and exact text metrics were not captured because the running reference timer and system settings were left unchanged.
